description: Use when rewriting existing prose for a clearer, shorter, warmer, more formal, or audience-shifted version.
---

# Rewrite procedure

1. Restate the rewrite goal in one line (e.g. cut 30%, warmer B2B tone).
2. Keep every factual claim, name, number, and link unless the user said
   to drop them.
3. Produce one full rewrite first. Do not interleave commentary inside it.
4. After the rewrite, list up to three concrete deltas (what changed and why).
5. If length was the ask, report approximate before/after word counts.
6. Offer one alternate opening sentence only when the original opening is weak.
